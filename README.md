# Gene Expression Clustering

This project groups genes with similar expression patterns in the CHO and Iyer datasets. The notebook compares K-means, Ward hierarchical clustering, and a Gaussian mixture. It checks the clusters against the supplied labels with adjusted Rand index and shows PCA and t-SNE plots.

Open `P2.ipynb` in Jupyter and run the cells from top to bottom. Keep `cho.txt` and `iyer.txt` beside the notebook. You will need Python with NumPy, pandas, Matplotlib, and scikit-learn.

The final write-up is `Clustering_report.pdf`.
